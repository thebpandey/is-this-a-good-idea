# Changelog

## 1.0.0 (2026-07-08)

Initial release.

- Three-domain routing: entrepreneurship, real estate investing, app/product builds
- App domain fork: market-facing (A1) vs internal workflow tool (A2), separate gates and weights
- Hard gates per domain, evaluated before any scoring
- Five-dimension weighted scorecard per domain, 1-5 scale with plain-language anchors
- Four-tier verdicts: GO / TEST FIRST / NO-GO / PIVOT
- Cross-domain decision layer: inversion, pre-mortem, expected-value tie-breaking, Working Backwards press-release test
- Evidence protocol with [VERIFIED] / [USER-SUPPLIED] / [ASSUMED] claim tags and a search-or-reasoning pause on load-bearing claims
- Fixed seven-section report format with mandatory opportunity cost line
- Deliverables for four platforms: Claude.ai, Claude Code, Codex CLI, ChatGPT Custom GPT
